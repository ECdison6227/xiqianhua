# 洗铅华 · 卷一

以华浅的视角走进故事：视觉小说主线、九段 2D 探索、酒楼六人物实时问答与带来源的手记。

[在线游玩](https://edsionc.top/xiqianhua/) · [项目介绍](https://edsionc.top/xiqianhuav)

## 快速体验

首页选择「入局一览 → 酒楼风波」。走近琵琶女询问意愿，再问蓝衣人为何出手；把姑娘的证词出示给华深，完成证词分类，回到原剧情。实时 AI 无法响应时，可在问答框切换「预设问答」。

完整阅读从「初入书中」开始。点击继续、空格或回车推进；探索使用 WASD / 方向键、点击地面移动，E 互动。手机建议横屏。

## 本地运行

需要 Node.js 22.12 或更高版本，建议 Node.js 24。

```sh
npm ci
cp .env.example .env.local
npm run build
npm start
```

打开 `http://127.0.0.1:3911/xiqianhua/`。`.env.example` 默认使用不调用外部模型的预设问答；正式 AI 配置只放在 `.env.local`。

若从 GitHub 克隆代码，请从[完整源码与素材包](https://edsionc.top/xiqianhua/downloads/xiqianhua-source.zip)取得 `public/` 目录，复制到项目根目录。完整下载包已包含运行素材。

```sh
npm test
```

检查覆盖原卷一全部剧情片段、八处选择、六个结局、九段探索可达性、存档恢复、角色信息隔离、证词出示、请求去重与 API 边界。

## 实现

- TypeScript 解释原卷一剧本；主线与结局由剧本控制。
- Phaser 负责场景行走、碰撞、寻路、人物与观察点。
- Express 提供六人物会话 API；模型只生成回应、情绪与候选线索 ID。
- 固定角色事实、独立会话记录、结构校验、线索白名单和部分越界语言检查共同约束生成。规则检查不能证明所有自然语言都正确。
- 游戏进度保存在浏览器，支持六个手动存档及 JSON 导入导出；人物会话由服务器保存。

`src/` 是游戏界面、剧情解释器、探索和小游戏；`server/` 是会话与模型适配；`shared/` 是公共类型及酒楼空间规则；`tests/` 是自动检查；`docs/` 记录来源和部署方法。

当前交付为浏览器整合版。原 Godot 交接包保留在制作工作区，不作为本仓库的另一份已验证发行版。

实现了九段探索、酒楼六人物问答、携证追问、来源手记、剧情小游戏、四款独立游艺及卷一阅读功能。已提供知乎连接入口、OAuth 回调和五项授权接口核验；用户已完成真实登录，创作与关注接口通过。收藏夹接口受到平台频率限制（30001），尚未实现知乎内容写入、多用户社交、全局记忆图谱或模型驱动的导演调度。

## 知乎账号接入

首页「关于 → 知乎账号连接」。登记回调应精确为 `https://edsionc.top/xiqianhua/auth/callback`。已按官方 Hackathon Skill 初始化，项目内保留原版 `.codex/skills/zhihu/`。公开配置在 `hackathon.config.json`，不包含凭据。

服务器私有环境需要 `ZHIHU_OAUTH_APP_KEY` 与 `ZHIHU_ACCESS_SECRET`；macOS 可从钥匙串读取。用户必须亲自确认知乎授权。未登录也可游玩，连接与断开不更改浏览器存档。

30 项本地检查通过，其中 11 项覆盖登录接口与凭据读取，不能替代真实授权。Access Secret 已经官方 CLI 在线验证。用户反馈真实 OAuth 登录、创作和关注接口成功，收藏夹列表受平台频率限制（30001），近期收藏为空。已修正依赖查询未执行却显示为空的问题，并增加安全的错误分类；收藏夹相关接口待平台恢复后复核。界面遇到限流会暂停核验 60 秒，等待结束后由用户手动重试，不自动重发请求。官方现阶段可能不回传 state，本项目沿用临时联调兼容模式并在界面标明。详见 [接入说明](docs/zhihu-integration.md)。
