# 洗铅华 · 卷一

以华浅的视角走进故事：视觉小说主线、九段 2D 探索、酒楼六人物实时问答与带来源的手记。

[在线游玩](https://edsionc.top/xiqianhua/) · [项目介绍](https://edsionc.top/xiqianhua/presentation.html)

## 快速体验

首页选择「入局一览 → 酒楼风波」。走近琵琶女询问意愿，再问蓝衣人为何出手；把姑娘的证词出示给华深，完成证词分类，回到原剧情。实时 AI 无法响应时，可在问答框切换「预设问答」。

完整阅读从「初入书中」开始。点击继续、空格或回车推进；探索使用 WASD / 方向键、点击地面移动，E 互动。手机建议横屏。

## 本地运行

需要 Node.js 22.12 或更高版本，建议 Node.js 24。

```sh
npm ci
cp .env.example .env.local
npm run build
npm start
```

打开 `http://127.0.0.1:3911/xiqianhua/`。`.env.example` 默认使用不调用外部模型的预设问答；正式 AI 配置只放在 `.env.local`。

若从 GitHub 克隆代码，请从[完整源码与素材包](https://edsionc.top/xiqianhua/downloads/xiqianhua-source.zip)取得 `public/` 目录，复制到项目根目录。完整下载包已包含运行素材。

```sh
npm test
```

检查覆盖原卷一全部剧情片段、八处选择、六个结局、九段探索可达性、存档恢复、角色信息隔离、证词出示、请求去重与 API 边界。

## 实现

- TypeScript 解释原卷一剧本；主线与结局由剧本控制。
- Phaser 负责场景行走、碰撞、寻路、人物与观察点。
- Express 提供六人物会话 API；模型只生成回应、情绪与候选线索 ID。
- 固定角色事实、独立会话记录、结构校验、线索白名单和部分越界语言检查共同约束生成。规则检查不能证明所有自然语言都正确。
- 游戏进度保存在浏览器，支持六个手动存档及 JSON 导入导出；人物会话由服务器保存。

`src/` 是游戏界面、剧情解释器、探索和小游戏；`server/` 是会话与模型适配；`shared/` 是公共类型及酒楼空间规则；`tests/` 是自动检查；`docs/` 记录来源和部署方法。
